# Quibly-AI — AI News Analysis Chatbot

Quibly-AI is an AI-powered chatbot that provides analysis, summaries, and insights on user-requested news topics using Generative AI and Groq API integration.

## 🚀 Features

* AI-based news analysis and summarization
* Real-time chatbot interaction
* Fast responses using Groq API
* Responsive modern UI
* Cross-device compatibility
* Clean and user-friendly interface

## ⚙️ Installation & Setup

Clone the repository:

```bash id="hij69t"
git clone https://github.com/26Utkarsh/Quibly-AI.git
```

Navigate to the project directory:

```bash id="z24r0u"
cd Quibly-AI
```

Install dependencies:

```bash id="0t4e6l"
npm install
```

Start the development server:

```bash id="8m9t3k"
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env id="6v8fow"
VITE_GROQ_API_KEY=your_groq_api_key
```
